# 1OPJ Examples

These scripts are setup templates for WT and N368S 1OPJ path simulations. Large input files are intentionally excluded.

Expected local inputs include:

- `example_inputs/1OPJ/WT/md.gro`
- `example_inputs/1OPJ/WT/topol.top`
- `example_inputs/1OPJ/N368S/md.gro`
- `example_inputs/1OPJ/N368S/topol.top`
- path-node `.gro` files and `.npy` point arrays referenced by each run script

Generated flux, walker, bin, trajectory, and visualization outputs should remain untracked.
