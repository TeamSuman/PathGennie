# Toy Example

`toy.py` defines a small OpenMM system with a 2D three-hole potential. `run_x.py` and `run_path1.py` show weighted-ensemble setup patterns using the installable `wepath` package.

Run from the repository root after installation:

```bash
python examples/toy/run_x.py
```

Channel flux smoke test:

```bash
python examples/toy/run_lower_channel_t200.py
```

By default this runs a short lower-channel CPU test at 200 K with 25 WE iterations and writes flux/bin/walker logs under `outputs/`. The upper and lower path collective variables are generated by a zero-temperature string relaxation against the three-hole potential gradient, then saved as `zts_mfep_<channel>_<temperature>.txt`. The runner pre-seeds one starting state per path-coordinate bin at iteration zero, then resamples each occupied bin to the configured walker count. Select the channel, temperature, and test length with:

```bash
python examples/toy/run_lower_channel_t200.py --channel upper --temperature 50 --iterations 100 --steps 50
```

Tune the string relaxation with `--zts-images`, `--zts-steps`, and `--zts-step-size`.

Use `--single-source` to recover the older left-basin-only initialization.

Because all bins are filled at iteration zero, target-side seeded walkers can warp during the first propagated iteration. Discard early burn-in iterations when estimating steady-state flux from pre-seeded runs.
